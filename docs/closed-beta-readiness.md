# VIIMsignal 클로즈드 베타 완료 기준

## 목표

대표·리더와 운영 담당자 1~3개 브랜드가 실제 계정으로 로그인해, 회사 데이터 파일을 넣고, 판매·재고 신호를 확인하고, AX 근거를 거쳐 실행을 승인한 기록까지 남길 수 있어야 한다.

## 골든 패스

1. 대표 계정 로그인과 회사 격리
2. 판매 파일 자동 유형 추천 → 컬럼 확인 → 적재
3. 재고 파일 자동 유형 추천 → 컬럼 확인 → 적재
4. 판매 현황·수익성·재고 운영·오늘 결정할 일 갱신
5. AX 질문 → 집계 근거·기준일·추천 행동 표시
6. 재고 이동 또는 재주문 승인
7. 생산 실행 큐와 감사 이력 반영
8. 사용자·페이지·국가·채널·위치 권한 검증

## 연결형 샘플 데이터

- `assets/templates/closed-beta/VIIMsignal_Closed_Beta_Sales_30D.csv`: 30일, 8개 SKU, 6개 채널, 1,440행
- `assets/templates/closed-beta/VIIMsignal_Closed_Beta_Inventory.csv`: 8개 SKU, 7개 위치, 56행
- 판매 파일에는 원가, 수수료, 마케팅비, 익명 고객 토큰, 시·군·구 배송권역, 반품 수량과 주문 상태가 포함된다.
- 직접 식별정보는 포함하지 않는다.

## 자동 검증

```bash
BETA_BASE_URL=https://signal.viimstudio.ai \
BETA_TEST_EMAIL='company-owner@example.com' \
BETA_TEST_PASSWORD='...' \
node scripts/closed-beta-smoke.mjs
```

실제 OpenAI 호출까지 검사할 때만 `BETA_SMOKE_AX=1`을 추가한다. 기본 검증은 비용과 대화 이력 생성을 피한다.

## 출시 차단 조건

- 회사 간 데이터 또는 AX 기록이 섞임
- 적재 성공 후 판매·재고 화면이 갱신되지 않음
- 승인 권한이 없는 사용자가 실행 가능
- AX 숫자와 동일 필터의 대시보드 집계가 다름
- 실패한 적재가 정상 데이터로 표시되거나 마지막 정상 데이터가 사라짐
- 고객 직접 식별정보가 AX 입력 또는 로그에 노출됨
