# VIIMsignal 2주 클로즈드 베타 실행안

## 목표

대시보드가 보이는지를 확인하는 테스트가 아니라, 리더와 팀이 실제 데이터를 보고 더 빠르게 결정하고 실행 기록을 남길 수 있는지를 검증한다.

## 1주차: 숫자와 추천 신뢰 확보

### 1일차

- 대표·관리자·팀 계정 로그인
- 페이지·국가·채널·위치 권한 확인
- 판매·재고 파일 적재와 정합성 확인

### 2일차

- 판매·재고·수익성 핵심 숫자를 기존 보고서와 대조
- 불일치 원인과 컬럼 매핑 수정
- 데이터 갱신 담당자와 시간을 확정

### 3~4일차

- AX 실제 질문 5개 실행
- 기준일·필터·근거·추천 행동 검토
- 추천과 기존 담당자 판단의 차이를 기록

### 5일차

- 재고 이동 또는 재주문 1건을 승인 전 단계까지 검토
- 실행하지 않을 경우 영향과 제약을 확인
- 주간 리뷰에서 사용성·정확성 이슈를 P0~P3로 분류

## 2주차: 통제된 실행 검증

### 6~8일차

- 담당자 확인을 거친 재고 이동 1건 승인
- 재주문 1건 승인 후 생산 실행 큐 생성 확인
- 실행 상태와 감사 이력 확인

### 9일차

- 추천 채택 결과와 실제 판매·재고 변화를 비교
- AX 응답 속도, 데이터 갱신 지연, 업무 절감 시간을 집계

### 10일차

- 대표·리더·운영자 인터뷰
- 계속 사용/수정 후 사용/제외 판단
- 다음 데이터 연결과 제품 범위를 결정

## 필수 성공지표

| 지표 | 계산 | 2주 목표 |
|---|---|---:|
| 골든 패스 성공률 | 완료 흐름 / 시도 흐름 | 100% |
| 데이터 정합성 | 일치 적재 / 전체 적재 | 100% |
| AX 근거 확인 가능률 | 근거가 확인된 답변 / 업무 질문 | 90% 이상 |
| 추천 검토율 | 검토한 추천 / 생성 추천 | 80% 이상 |
| 추천 채택률 | 승인·실행 추천 / 검토 추천 | 측정 후 기준 설정 |
| 의사결정 시간 | 기존 대비 검토 시간 변화 | 30% 단축 가설 |
| 응답 성능 | 일반 페이지 전환·AX 응답 | 페이지 1초 이내, AX 8초 이내 또는 폴백 |
| P0/P1 해결 | 목표시간 내 해결 / 전체 | 90% 이상 |

효과 금액은 실제 매출로 단정하지 않고 `보호 가능 매출`, `예상 과잉재고 방지`, `예상 할인비 절감`으로 구분한다.

## 인터뷰 질문

1. 오늘 무엇을 결정해야 하는지 더 빨리 알 수 있었는가?
2. AX의 숫자와 근거를 신뢰할 수 있었는가?
3. 기존 보고서보다 줄어든 확인 작업은 무엇인가?
4. 실행 버튼을 누르기 전에 추가로 필요한 제약은 무엇인가?
5. 매일 보게 될 페이지와 보지 않을 페이지는 무엇인가?
6. 다음으로 연결해야 할 외부 데이터는 무엇인가?
