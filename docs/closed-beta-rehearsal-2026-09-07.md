## 운영자가 매일 확인할 화면

1. **데이터 연결**: 최근 정상 반영, 정합성, 일부 오류 파일의 갱신 차단 여부
2. **오늘의 액션**: P0/P1, 결정 기한, 담당팀, 승인 후 자동 생성 범위
3. **생산**: 재주문 승인 기반 생산오더와 다음 공정
4. **실행·성과**: 이동 요청의 출고·입고 및 D+7·14·28 결과
5. **사용자·권한**: 역할별 메뉴·승인 권한과 감사 이력

## 발견·조치한 이슈

- 이전 정적 번들을 연 채 운영하면 최신 팀 실행 패널이 보이지 않을 수 있어 새 배포 후 새로고침이 필요하다.
- 팀 실행 업무가 공용 결정 잠금 상태를 공유해 버튼이 무응답이 될 수 있는 구조를 전용 `operationalTaskBusy` 상태로 분리했다.
- 상태 변경 직후 다른 서버리스 인스턴스의 30초 캐시가 남을 수 있어, 강제 조회 시 조회 API가 `decision-actions` 캐시를 직접 비우도록 수정했다.
- API 첫 호출은 서버 콜드 스타트 영향으로 1~3초가 걸릴 수 있으므로 운영 테스트는 첫 호출과 반복 호출을 분리해 기록한다.
